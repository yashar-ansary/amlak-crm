# سامانه مدیریت هوشمند معاملات املاک و CRM پارس ملک (ParsMelk)

سامانه جامع، اختصاصی و مدرن مدیریت فایل‌های ملکی، مشتریان، قراردادها و تقویم کاری مشاوران با پشتیبانی کامل از **دستیار صوتی هوش مصنوعی (Voice AI)** به زبان فارسی.

---

## ۱. راهنمای اجرای سریع با داکر (Docker & Docker Compose)

### پیش‌نیازها:
- نصب بودن **Docker** و **Docker Compose** بر روی سیستم یا سرور لینوکس/ویندوز.

### مراحل اجرا:
۱. فایل پروژه را از حالت فشرده خارج کنید:
```bash
unzip parsmelk-crm.zip
cd parsmelk-crm
```

۲. فایل پیکربندی محیطی `.env` را ایجاد و کلید هوش مصنوعی را در آن قرار دهید:
```bash
cp .env.example .env
nano .env
```
محتوای `.env`:
```env
GEMINI_API_KEY="کلید_اختصاصی_جمینای_شما"
PORT=3000
NODE_ENV=production
```

۳. اجرای کانتینر با داکر کامپوز:
```bash
docker compose up -d --build
```

۴. برنامه هم‌اکنون روی پورت `3000` در دسترس است:
- در دسکتاپ: `http://localhost:3000`
- در شبکه محلی یا سرور: `http://SERVER_IP:3000`

---

## ۲. راهنمای ویژه سرویس صوتی (Voice AI)، سرور داکر و Nginx Proxy با SSL

### چرا در پیش‌نمایش کار می‌کرد اما روی سرور و Nginx Proxy نیاز به تنظیم دارد؟
سرویس صوتی و تایپ زنده شامل دو لایه هوشمند است:
1. **لایه فرانت‌اند (Web Speech API مرورگر):** برای تایپ کلمه به کلمه هنگام تکلم. این لایه مستقیماً توسط مرورگر اجرا شده و نیازمند دسترسی به میکروفون (پروتکل امن HTTPS یا localhost) و ارتباط با سرویس گفتار است. در مرورگر گوگل کروم، تشخیص گفتار به سرورهای کلود گوگل (`speech.googleapis.com`) وصل می‌شود که در داخل ایران ممکن است فیلتر باشد (خطای `network`).
2. **لایه بک‌اند سرور (هوش مصنوعی Gemini):** برای رونویسی کامل فایل‌های صوتی ضبط‌شده در مواردی که کاربر آفلاین است، اینترنت داخلی دارد یا از مرورگر بدون Web Speech استفاده می‌کند.

### راهنمای تنظیم Nginx Reverse Proxy با SSL (حل قطعی مشکل دریافت صدا):
یک فایل نمونه کامل و آماده به نام **`nginx.conf.example`** در ریشه پروژه قرار داده شده است. مهم‌ترین تنظیماتی که در Nginx باید اعمال کنید:

```nginx
# ۱. حیاتی: افزایش حجم مجاز دریافت صوت (پیش‌فرض Nginx فقط ۱ مگابایت است)
# بدون این خط، Nginx خطای 413 (Payload Too Large) داده و صدا به سرور نمی‌رسد:
client_max_body_size 50M;

# ۲. صدور مجوز میکروفون در هدر مرورگر:
add_header Permissions-Policy "microphone=(self)" always;

location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    
    # ۳. اعلام پروتکل امن HTTPS به کلاینت و کانتینر
    proxy_set_header X-Forwarded-Proto https;
    proxy_set_header X-Forwarded-Ssl on;
    
    proxy_read_timeout 300s;
    proxy_buffering off;
}
```

### تنظیم کلید هوش مصنوعی در سرور داکر (جهت تبدیل ۱۰۰٪ قطعی صوت به متن):
اگر مرورگر به دلیل فیلترینگ نتواند به سرور گفتار گوگل وصل شود، سامانه صدا را مستقیماً ضبط کرده و به بک‌اند سرور ارسال می‌کند. برای اینکه سرور بتواند صوت را به متن فارسی تبدیل کند:
۱. فایل `.env` را در کنار `docker-compose.yml` در سرور ایجاد کنید:
```env
GEMINI_API_KEY="کلید_جمنای_شما"
```
۲. دستور بیلد مجدد را اجرا کنید:
```bash
docker compose up -d --build
```
اکنون چه در محیط دسکتاپ، چه در اندروید و چه در آیفون، حتی با فیلترینگ یا بدون وب‌اسپیچ، تبدیل صوت به متن با بالاترین دقت انجام خواهد شد.

## ۳. اجرای بدون داکر (با Node.js)

```bash
# ۱. نصب پیش‌نیازها
npm install

# ۲. بیلد و اجرای نسخه نهایی
npm run build
npm start
```
