# سامانه مدیریت هوشمند معاملات املاک و CRM پارس ملک (ParsMelk)

سامانه جامع، اختصاصی و مدرن مدیریت فایل‌های ملکی، مشتریان، قراردادها و تقویم کاری مشاوران با پشتیبانی کامل از **دستیار صوتی هوش مصنوعی (Voice AI)** به زبان فارسی.

---

## ۱. راهنمای اجرای سریع با داکر (Docker & Docker Compose)

### پیش‌نیازها:
- نصب بودن **Docker** و **Docker Compose** بر روی سیستم یا سرور لینوکس/ویندوز.

### مراحل اجرا:
۱. فایل پروژه را از حالت فشرده خارج کنید:
```bash
unzip parsmelk-crm.zip
cd parsmelk-crm
```

۲. فایل پیکربندی محیطی `.env` را ایجاد و کلید هوش مصنوعی را در آن قرار دهید:
```bash
cp .env.example .env
nano .env
```
محتوای `.env`:
```env
GEMINI_API_KEY="کلید_اختصاصی_جمینای_شما"
PORT=3000
NODE_ENV=production
```

۳. اجرای کانتینر با داکر کامپوز:
```bash
docker compose up -d --build
```

۴. برنامه هم‌اکنون روی پورت `3000` در دسترس است:
- در دسکتاپ: `http://localhost:3000`
- در شبکه محلی یا سرور: `http://SERVER_IP:3000`

## ۲. راهنمای ویژه سرویس صوتی (Voice AI) در گوشی موبایل و سرور داکر

### چرا در پیش‌نمایش صدا کار می‌کرد اما در داکر روی گوشی کار نمی‌کند؟
مرورگرهای تلفن همراه (Google Chrome در اندروید و Apple Safari در آیفون) طبق استانداردهای امنیتی وب جهانی (W3C Secure Context):
- دسترسی مستقیم به میکروفون (`getUserMedia`) و تبدیل گفتار به نوشتار زنده (`Web Speech API`) را **فقط و فقط بر روی پروتکل امن HTTPS یا آدرس localhost** مجاز می‌دانند.
- اگر سرور داکر را با آدرس IP مستقیم بدون SSL باز کنید (مثلاً: `http://192.168.1.100:3000`)، مرورگر گوشی دسترسی به میکروفون وب را به دلایل امنیتی قفل می‌کند.

### راهکارهای ارائه‌شده در سامانه:

#### راهکار ۱ (خودکار و بدون نیاز به تنظیمات): استفاده از دکمه «ضبط با ریکوردر گوشی»
در پنل مشاور و فرم ثبت صوتی ملک، دکمه **«ضبط با ریکوردر گوشی (آیفون / اندروید)»** تعبیه شده است. این قابلیت حتی روی آدرس‌های HTTP بدون SSL نیز به صورت ۱۰۰٪ تضمینی کار می‌کند؛ ضبط‌صوت پیش‌فرض گوشی شما باز شده و پس از اتمام صحبت، فایل صوتی مستقیماً به سرور ارسال و توسط هوش مصنوعی پیاده‌سازی و ثبت می‌شود.

#### راهکار ۲ (پیشنهادی برای محیط تولید): فعال‌سازی HTTPS با Caddy یا Nginx
برای اینکه بتوانید در گوشی موبایل مانند دسکتاپ همزمان با صحبت کردن، متن کلمات را به صورت زنده و تایپ‌شده ببینید، کافیست یک وب‌سرور سبک مانند Caddy را به عنوان ریورس‌پروکسی قرار دهید تا به طور خودکار گواهی SSL رایگان صادر کند:

نمونه کانفیگ `Caddyfile`:
```caddy
crm.yourdomain.com {
    reverse_proxy app:3000
}
```

#### راهکار ۳ (مخصوص تست لوکال در گوگل کروم اندروید):
اگر داکر را روی شبکه محلی اجرا کرده‌اید و دامنه ندارید:
۱. در مرورگر کروم گوشی اندروید وارد آدرس زیر شوید:
   `chrome://flags/#unsafely-treat-insecure-origin-as-secure`
۲. این گزینه را روی `Enabled` قرار داده و آدرس سرور داکر خود را وارد کنید (مثال: `http://192.168.1.100:3000`).
۳. مرورگر را Relaunch کنید. اکنون میکروفون وب دقیقاً مانند حالت پیش‌نمایش به صورت زنده در گوشی کار خواهد کرد.

## ۳. اجرای بدون داکر (با Node.js)

```bash
# ۱. نصب پیش‌نیازها
npm install

# ۲. بیلد و اجرای نسخه نهایی
npm run build
npm start
```
